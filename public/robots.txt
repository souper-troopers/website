#
# Why these are listed explicitly rather than left to the `User-agent: *` rule: the
# crawlers below split into two kinds that are easy to conflate, and blocking the wrong
# one has the opposite effect to the one intended.
#
#   * Training crawlers (GPTBot, ClaudeBot, CCBot, Google-Extended) collect pages for
#     model training. Blocking them does NOT remove the site from an assistant's answers.
#   * Search-time fetchers (OAI-SearchBot, PerplexityBot, and Bingbot, which several
#     assistants search through) fetch a page at the moment somebody asks a question.
#     Blocking one of these DOES remove the site from those answers.
#
# Souper Troopers wants to be recommended when somebody asks an assistant which charities
# help homeless people in Cape Town, so both kinds are allowed. This is a decision rather
# than a default — it is recorded on /request-for-comment under "Choices worth knowing
# about" so the client can reverse it. Reversing it means Disallow, not deletion: a
# crawler with no rule falls back to `User-agent: *`.
#
