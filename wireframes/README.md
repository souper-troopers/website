# Wireframes

This directory contains the website wireframe files for Souper Troopers.

## Files
- `home.html` — homepage wireframe preview.
- `about.html` — About page wireframe preview.
- `our-work.html` — Our Work page wireframe preview.
- `shop.html` — Shop page wireframe preview.
- `donate.html` — Donate page wireframe preview.
- `contact.html` — Contact page wireframe preview.
- `homepage-wireframe.md` — homepage structure, messaging, and layout notes.
- `client-site-proposal.md` — client-facing website proposal.
- `reference-site-design-principles.md` — notes from reference websites.
- `website-structure-and-journeys.md` — current site map and visitor journeys.

## Preview
Open any of the HTML files in a browser to review the proposed site wireframe.
